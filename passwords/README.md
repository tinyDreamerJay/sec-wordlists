# passwords 字典

## 来源

国内权重段（`passwords.txt`，224487 行，占全文 100% 的国内来源），全部来自国内仍在维护的字典项目：

- **fuzzDicts**（TheKingOfDuck）`passwordDict/`：`top1000.txt`、`top3000.txt`、`top19576.txt`
  是近年国内攻防演练/实战排序口令表；`某集团下发的弱口令字典.txt`（96807 行）是国内企业内网
  实际下发排查用的口令；`birth.txt` 为 1980–2010 年月日生日；`webshell-pass.txt` 为国产
  webshell/中间件口令。
- **SaiDict**（Stardustsky）`Account/pass.txt`（24103 行）：国内运营商与企业环境实证弱口令
  （含 `jtserver1981@223`、`wztelecom2008easyget` 这类企业缩写+年份+符号的真实形态）。

国际基线不再混进主文件，单独放 `passwords-intl.txt`（100000 行，Probable-Wordlists
Top304Thousand 概率序前段 + SecLists `10k-most-common.txt`）。这是上一版权重偏的根因：
西方 rockyou 系数据排在前面，对国内目标命中率低，现已分离。

## 适用方位

用于在线喷洒/撞库与离线爆破：**前 3570 行**打登录接口与堡垒机/VPN/邮箱/域账号的快速试探，
`--top` 截断时优先生效；`88603` 起的集团段与 SaiDict 段用于内网横向时的本地下发字典复现；
生日段配合 `usernames/` 的姓名拼音做「姓名+生日」组合。
判据是登录响应差异（状态码、跳转链、`Set-Cookie` 有无、错误文案长度与时延）；
在线场景按账号锁定阈值与 WAF 速率限制降并发，离线场景直接用 `hashcat -m 0 -a 0` 加载。
