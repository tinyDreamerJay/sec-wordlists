# usernames 字典

## 来源

国内权重段（`usernames.txt`，130660 行），来自国内字典项目 fuzzDicts `userNameDict/` 与
SaiDict `Account/`：

- `top500.txt`：近年国内系统/设备默认账号与高频账号（admin、test、weblogic、manager、super…）。
- `中文姓名(简写、全拼).txt`：姓名拼音简写（`cb`、`chenjh`、`zjb`）1294 行。
- `user.txt`：账号基础表 8886 行，剔除 SQL 注入式条目（含引号/空格/括号/斜杠）后保留 8830 行。
- `Account/phone.txt`：**真实泄露手机号 131653 行**，取前 60000 行——国内账号很大比例是手机号。
- `test-phone.txt`：手机号模板 329 行（13000000000 这类占位规则）。
- `top300_lastname.txt`：189 个姓氏拼音，按频次序作为分组轴。
- `ChinaUserName.txt`：398645 行拼音全拼穷举。**注意**：该文件按字母序生成，直接取前 N 行会
  全部落在 `l` 开头的姓上（`liai`/`liaiai`），权重严重偏斜；这里改为按 189 个姓氏的最长前缀
  分组后**轮询取样** 60000 行，让 li/wang/zhang/liu/chen 等常见姓各占一份。

国际基线单独放 `usernames-intl.txt`（20000 行，SecLists 英文用户名），不进主文件。

## 适用方位

用于账号枚举与撞库组合：先打默认账号段定位未改初始账号的系统（设备、中间件、监控平台），
再用手机号段匹配「以手机号为登录名」的国内站点（政务、教育、企业 OA、SaaS），
姓名拼音段配合 `passwords/` 生日段做 `zhangsan1990` 一类组合。
判据是「用户不存在」与「密码错误」两类响应的文案/状态码/时延差异，或注册、找回密码接口的回显；
有频率限制时按账号维度而非 IP 维度限速，避免一次性触发风控。
